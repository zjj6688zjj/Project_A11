## 🤔 为什么用 Emoji？

1. **👁️ 直观**：一眼看出状态（✅ 成功 ❌ 失败）
2. **✨ 美观**：比纯文字更生动
3. **🌍 通用**：跨平台显示一致

## 💻 Windows 兼容性问题

> **⚠️ Windows 命令行默认编码可能无法正确显示 Emoji**

### ✅ 解决方案

1. **💻 使用 VS Code 终端** - 完全支持 Emoji
2. **💻 使用 Windows Terminal** - 支持大部分 Emoji
3. **📝 使用替代文字** - 如果显示异常，使用方括号内的替代文字

## 📖 文档中的 Emoji 使用规范

### 📌 标题和章节

- 使用 ⚠️ 表示重要警告
- 使用 💡 表示关键信息
- 使用 ✅ 表示推荐/最佳实践

### 📊 表格和列表

- 使用 ✅ 表示达标/成功
- 使用 ❌ 表示不达标/失败
- 使用 ⚠️ 表示警告/注意
